# Image Helper & Migrator

Актуальные хелперы для изображений товаров.

## Файлы

- `Image.php` - пресеты ресайза и единая точка подготовки изображений для шаблонов.
- `ImageMigrator.php` - переносит старые ссылки из `LINK_PHOTO` в файловое свойство `LINK_PHOTO_FILE`.

## Автоматическая Обработка 1С

Во время `OnSuccessCatalogImport1C` для `import___*.xml` вызывается `brakes_1c_images_schedule()`.

Она делает две вещи:

- читает реквизит `Ссылки на фото` и синхронизирует строковое свойство `LINK_PHOTO`;
- если XML содержит реальные картинки, переносит их в файловое свойство товара.

События пишутся в `CEventLog` с `AUDIT_TYPE_ID=BRKS_1C_IMAGE`.

## Ручной CLI-Запуск

Точка входа:

```bash
php local/cron/image_migrator.php --start-id=0 --chunk=200
```

Флаги:

- `--id=<ELEMENT_ID>` - обработать один элемент.
- `--start-id=<ID>` - начать с указанного ID.
- `--chunk=<N>` - размер пачки, по умолчанию 200.
- `--limit=<N>` - максимум элементов, `0` означает весь каталог.
- `--dry-run` - проверить без записи.
- `--force` - заменить уже заполненное `LINK_PHOTO_FILE`.
- `--delete-source` - удалить исходник из `/fotoz` после успешного переноса.

`--delete-source` использовать осторожно: `/fotoz` сейчас считается рабочим источником для миграции и не чистится автоматически.

## Что Не Делает Мигратор

- Не обновляет цены.
- Не обновляет остатки.
- Не строит разделы каталога.

Цены и остатки приходят стандартным 1С-обменом. Разделы и служебные свойства поддерживает `local/cron/1c_catalog_parse.php`.
